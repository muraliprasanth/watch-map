# Future issue prevention: watch-map (published copy)

Written 2026-11-17. Update it when a limit or a risk changes.

| Limit or risk | Detail | What happens | Prevention |
|---|---|---|---|
| This is a published copy | The guide is built elsewhere and copied here by a script | An edit made here is overwritten at the next publish | Do not edit here |
| Unofficial fan guide | No Marvel logo, artwork or music is used | Adding them risks a takedown | Keep it that way |
| Public repository, served as plain files | `.nojekyll` is present, so every file has a public address | A stray file is published | Only the guide's own files belong here |
| Wallpapers are large | Originals load only on click | Loading them on view would use up GitHub Pages' monthly traffic allowance (about 100 GB) | Keep the click-to-load; keep the photo credits |
| Ticks stay in the browser | Nothing is saved on a server | Clearing browser data loses them | By design |
| A second copy exists on another host | Both are published from the same source | This one can be a version behind | Publish both together |
