# Watch Map

An unofficial fan guide to the Marvel Studios films, series and specials: what to watch first, release
order and story order, watch paths, main characters, and a tick list of what you have seen.

This repository holds only the finished page, served by GitHub Pages. It is a copy of the same guide that
runs at https://mcu-watch-map.pages.dev.

- Not affiliated with Marvel or Disney. Titles and character names belong to their owners.
- The picks ("watch first", "adds colour", paths) are this guide's own suggestions.
- The headline typeface is Anton, under the SIL Open Font License (`fonts/OFL.txt`).
- The page stores your ticks in your own browser and sends nothing anywhere.
